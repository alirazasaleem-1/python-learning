## ▶️ Running anything

```bash
pip install -r 04-mini-projects/python-projects/requirements.txt
python "01-python-60-days/DAY 05/04_the_multiplication_table.py"
```

Some day-folder scripts read or write small files (`diary.txt`, `weather_data.json`, `TestFolder/`) inside `01-python-60-days`. Run them from that folder.
