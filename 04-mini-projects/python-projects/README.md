# 🐍 Python Projects

A collection of beginner-to-intermediate Python command-line projects I built while learning Python. They cover file handling, JSON/Excel persistence, REST APIs, web scraping, encryption, and data visualization.

## 📂 Projects

| Project | What it does | Concepts |
|---|---|---|
| [Computer Quiz Game](computer_quiz_game.py) | Interactive quiz with score tracking | Dictionaries, loops, JSON (`scores.json`) |
| [Daily Life Tracker](daily_life_tracker.py) | Logs daily activities to an Excel workbook | `openpyxl`, `datetime`, file I/O |
| [Expense Tracker](expense_tracker.py) | Add expenses and view running totals | Lists, tuples, menu-driven CLI |
| [Life Energy Dashboard](life_energy_dashboard.py) | Tracks daily energy levels and plots trends | JSON, `matplotlib` |
| [Password Manager](password_manager.py) | Stores passwords encrypted with a local key | `cryptography.fernet`, `getpass` |
| [Smart File Organizer](smart_file_organizer.py) | Sorts files in a folder into sub-folders by type | `os`, `shutil` |
| [Weather API System](weather_api_system.py) | Fetches weather for a city and saves it as JSON | `requests`, REST APIs, JSON |
| [Web Scraper (BBC News)](web_scraper_bbc_news.py) | Scrapes the latest BBC News headlines | `requests`, `BeautifulSoup` |

## 🚀 Getting started

```bash
git clone https://github.com/alirazasaleem-1/python-learning.git
cd python-learning/04-mini-projects/python-projects
pip install -r requirements.txt
python expense_tracker.py
```

Each script is standalone. Run any of them with `python <script_name>.py`.
